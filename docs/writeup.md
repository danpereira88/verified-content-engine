# Verified Content Engine

AI writing tools produce fluent marketing copy with no idea which statements are true, so I built a multi-agent system that writes product-marketing content and blocks every factual sentence it can't trace to the product's own documentation. Teams add product docs (the only source allowed to create facts), example copy (voice only) and positioning material (angle only). Extractors turn these into a claims registry where every fact has a permanent ID and an exact source quote, plus a style profile and a positioning pack. A strategist and a copywriter then write a draft in which every fact is tagged. Four independent checkers (an accuracy gate, a style checker, a best-practice auditor and a synthetic buyer) review it in parallel, and plain code, not a model, decides whether it is Blocked, Flagged or Approved. After at most two automatic revisions a person takes over, and any override needs a logged, written reason. Tested on two invented products with deliberately planted doc traps, the offline baseline caught 97–99% of false or overstated sentences, wrongly blocked 6–9% of true ones and caught every untagged fact, including on a product the rules were never tuned on; the next step is to confirm these results with the Claude-backed verifier.
