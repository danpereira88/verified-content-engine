# Shiftwell release notes

This page lists Shiftwell Cloud and Shiftwell Mobile releases. Newer entries are at the top.

## Release 5.3 (2025-11-24)

### New

- Auto-Fill Scheduling is now generally available for all Enterprise organizations.
- Schedulers can now offer an open shift to a chosen group of staff.
- Shiftwell Web now shows late sick calls in a separate column.

### Fixed

- Fixed an issue where some swap requests did not expire after 48 hours.

## Release 5.1 (2025-06-09)

### New

- Locations can now allow automatic swap approval.
- Shiftwell now posts open-shift alerts to Microsoft Teams and Slack channels.
- Administrators can now set a minimum rest period between two shifts.

### Changed

- The maximum number of shift templates per location increased from 20 to 40.

## Release 5.0 (2025-02-17)

### New

- Shiftwell Time Clock now accepts NFC staff badges.
- Shiftwell Mobile now sends overtime alerts to Schedulers.

### Fixed

- Fixed an issue where timesheets did not include breaks after a rota change.

## Release 4.8 (2024-10-07)

### New

- Shiftwell On-Premises is now available for Enterprise customers who host the service on their own network.
- The Shiftwell audit log now records the previous value of every rota change.
- Shiftwell Web is now available in Welsh.

## Shiftwell Mobile 4.2 (2024-08-19)

### New

- Shiftwell Mobile is now available in Polish.
- Approved timesheets can now be exported as XLSX.
