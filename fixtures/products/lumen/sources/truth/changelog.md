# Lumen Hub release notes

This page lists Lumen Hub firmware and Lumen app releases. Newer entries are at the top.

## Firmware 3.3 (2025-11-18)

### New

- Occupancy Forecasting is now generally available for all Enterprise sites.
- Lumen Hub can now pre-cool zones before a demand response event.
- The Lumen app now shows a 7-day CO2 trend for each zone.

### Fixed

- Fixed an issue where some Lumen Sensors reported humidity above 100% after a battery change.

## Firmware 3.2 (2025-06-02)

### New

- Lumen Hub now writes BACnet/IP objects.
- Lumen Hub now supports OpenADR 2.0b demand response events.
- Administrators can now postpone firmware updates.

### Changed

- The maximum number of zones per Lumen Hub increased from 12 to 16.

## Firmware 3.1 (2025-02-10)

### New

- Lumen Sensors now report CO2.
- The Lumen app now sends low-battery alerts.

### Fixed

- Fixed an issue where schedules did not resume after a power outage.

## Firmware 3.0 (2024-10-01)

### New

- Lumen Edge Server is now available for Enterprise customers who host the management service on site.
- The Lumen audit log now records the previous value of every configuration change.
- Lumen Hub now supports Power over Ethernet.

## Lumen app 2.8 (2024-08-12)

### New

- The Lumen app is now available in Dutch.
- Energy reports can now be exported as PDF.
